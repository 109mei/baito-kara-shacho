くわしい企画と決まりは、次の2つの文書を正とします。

- 企画書：https://claude.ai/artifact/B3UfitrusNtTW2CP9dJy4v
- 仕様書：https://claude.ai/artifact/2E54RmpMUxKBVXjrSKisyy

## 1. 概要と、今回作る範囲

アルバイトをしながら、好きな商売を選んで小さく始め、独立するまでを遊ぶ経営ゲーム。
選べる商売は、手作りの品・便利屋・個人開発の3つ（掛け持ちもできる）。
店、立地、審査、景気、疲れ、裏の道は、この試作には入れていない。

## 2. 画面

| 画面 | 出すもの |
|---|---|
| 最初の画面 | 街の絵（ゆっくり昼夜が回る）と題名、商売を選ぶ3枚の札 |
| 街の絵 | 立体的な1地区（自宅、アルバイト先、材料の店、道具の店、売り場、客先3つ、公園）。昼夜の空、影、窓の明かり、車、歩く人、自分。場所には役割の色の印（今日行く所だけ大きい） |
| 街の上に重ねる表示 | 日付、現金、今月の進み、現金があと何日もつか、働き方、いまいちばん足りないもの1つ、今日の時間割の帯 |
| ホーム | 届いた話（受ける・断る）、受けた話の進み、作品、今月ここまでの帯 |
| 商売 | 知名度、月に届く話の目安、道具、材料と仕入れの目安、作品を始める |
| 時間割 | 平日と休日の型（1時間きざみ16枠）。働けるのは1日12時間まで |
| 人 | 応募してきた人、雇った人の割り当てと時間 |
| お金 | 今月の途中経過、現金の推移、働き方（辞める・戻る）、設定（手でやる操作・音・動き）、セーブの書き出しと読み込み |
| 月末の締め | 商売の利益、内訳、先月からいちばん動いた数字、知名度 |

## 3. ルール

- 状態を持つのはルール本体（src/core）だけ。画面は命令を渡して、写しを読む。
- 刻みは1日（中で1時間ごとに時間割を処理する）。1か月は30日（平日22日・休日8日）。
- 命令：商売を選ぶ／始める、話を受ける／断る、時間割を塗る、仕入れの目安、売り込み先、道具を買う、作品を始める、雇う／外す／割り当てる、辞める／戻る、月を閉じる。
- 乱数は種つき。使うのは、届く話の数のゆらぎ・数量・届く日・納期、応募者、作品の当たり外れ。
- 届く話は月の初めに作られ、届く日になると見える。返事は3日以内。断っても何も失わない。
- 納期に間に合わないと、その話は流れ、月末に知名度が下がる。
- 手でやる操作（並べる・なぞる・タップ）の結果は3段。上出来は時間が1割短く、やり直しは2割長い。
- 月末に、アルバイト代と作品の入金が入り、人件費と生活費が出る。現金が足りない月が2回続くと、やり直し。
- 独立していて、3か月続けて月末の現金が減らなければ「独立 達成」。

## 6. セーブ

localStorage に、版番号つきで保存する（窓口は src/save/SaveStore.ts の1つだけ）。
命令のたびと、日を進めるたびに保存する。書き出しと読み込みができる。
閉じている間は時間が進まない。

## 7. 操作

タップが基本。手でやる操作の「なぞる」だけドラッグ。言葉や街の印を長押しすると、意味が1行出る。

時間の進め方：
- 「1日」は押した瞬間に進み、街の絵が朝→夜→次の朝を約1.8秒で見せる。
- 「1週」「月末まで」は1日ずつ見せながら進み、「止める」で途中で止められる。自分が決めることができたら自動で止まる。

## 8. 見た目・音の決まり

くわしい基準と点検の記録は [QUALITY_BAR.md](QUALITY_BAR.md)。

- 絵と音は、すべてコードで作る（画像・音声のファイルは使わない）。街の絵は PixiJS、音は Web Audio で合成する。
- 説明の文は出さない。出すのは札と数字の名前だけ。最初に触れるものを1つだけ光らせる。
- 書体は1つ。色は役割で分ける（街の印と時間割は同じ色の決まり）。形も役割で分ける（券・ボタン・板・札・帯）。
- 色の主役は空。光るのは本当に明るい物だけ。行き先だけ暖かい輪で目立たせる。
- グラフに横の目盛線は引かない。
- 広い面の明るさを速くくり返して変えない（まとめて進めるときは昼夜を切り替えない）。
- 設定で「音 なし」「動き 少なめ」を選べる。遅い端末では、街の絵の細かさを自動で下げる。
