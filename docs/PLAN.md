# 作り直しの計画（2D の見下ろし型・自由に動ける広い街）

前の版（小さな立体の街と経営の札）は `diorama-v1` の印（タグ）に残してある。ここからは作り直し。

## 何を作るか
- 見下ろし型の 2D。街の地図の見た目（大通り＝だいだい、細い道＝白、川と海＝青、公園＝緑、区画＝地区ごとの淡い色）。
- 街は種から自動生成する架空の街。約 8km 四方。大通りの格子、細い道、川と橋、海、公園、地区（都心・商業・住宅・工業）。
- 歩き・自転車・車で、止められずに動ける。車は盗める。
- 場所に近づいて入ると、行動の札が出る（アルバイト、店、銀行、空き店舗で事業、質屋、解体屋、警察署、ATM、留守の家）。
- 手配度（星 0〜5）。パトカーが追い、捕まると罰金・没収・時間が飛ぶ。星5で賞金稼ぎ。
- お金は「きれいなお金」と「汚れたお金」。汚れたお金は大きな買い物に使えず、自分の事業を通すと少しずつきれいになる。

## 構成（browser-game-stack の決まり）
- src/core/city.ts：街を作る（Pure TS、種つき）　src/core/sim.ts：状態・1コマ進める・命令
- src/data：balance.json＋Zod　src/world/MapView.ts：PixiJS で地図と車を描く
- src/ui：React（上の表示・操作・札・地図）　src/store：橋渡し　src/save：保存
