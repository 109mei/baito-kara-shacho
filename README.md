# バイトから社長（仮の題）

地図の見た目の広い街（約 8km 四方）を、歩き・自転車・車で自由に動き回る、見下ろし型の 2D ゲームです。
はたらく、事業を始める、法を破る、どれも選べます。スマホの縦画面のブラウザで遊べます。

- 遊ぶ：https://109mei.github.io/baito-kara-shacho/ （公開の設定後）
- 仕様：[docs/SPEC.md](docs/SPEC.md)

絵と音は、すべてコードで作っています（画像・音声のファイルは使っていません）。
前の版（小さな立体の街）は、印（タグ）`diorama-v1` に残してあります。

## できること（まじめにかせぐ側）

- **アルバイトから独立まで**：手作りの品（作って売り場に納める）、便利屋（届いた話を受けて客先へ行く）、個人開発（作品を作って発売する）。知名度が上がると、受けられる仕事が増える。
- **月末の締め**：給料・家賃・返済・生活費・税を払う。払えない月が2回続くと倒産。信用の点で、借りられる額と通る審査が変わる。
- **商売を広げる**：屋台と店（値段・広告・競合）、人を雇う（面接・不満・店長）、アパート、会社との契約、工房（工程と機械）、バスの路線、建設・運送・警備の許可と入札、法人にして社長になる。
- **街の動き**：景気、出来事と保険、空き巣と防犯。
- **手でやる操作**：並べる・なぞる・タップ。「おまかせ」で省ける。
- くわしい決まりと数値は docs/SPEC.md の 3-5。

## できること（法を破る側）

- 建物に入ると、その建物の中の画面に切り替わる。
- **強盗**：コンビニ（手薄）→ 宝石店 → 銀行の順に守りが固い。銃で店員や警備員を脅す、ノートPCで監視カメラを止める、正面か裏口かを選ぶ、鍵やピッキング道具で扉を開ける、ドリルで金庫を破る。だれにも見られずにやり切れば、手配されない。
- **組織と縄張り**：街は6つの縄張りに分かれている。敵のアジトの見張りを倒して金庫と縄張りを奪う。奪い返しもある。
- **ほかの人と一緒に遊ぶ**：claude.ai のページとして開くと、同じページをいま開いている人が街に見えて、撃ち合える（GitHub Pages では 1人用）。
- くわしい決まりと数値は docs/SPEC.md の 3-1〜3-4。

## 動かし方

```
npm install
npm run dev      # 開発用に開く
npm test         # 街とルール本体のテスト
npm run sim      # 受け入れ条件のシミュレーター（模型に各1,000回 遊ばせる）
npm run build    # 公開用に組み立てる
npm run e2e      # 実際のブラウザでの動作テスト（先に npm run build）
```

## フォルダ

| 場所 | 中身 |
|---|---|
| src/core | 街を作る（city.ts）、ルール本体（sim.ts）。画面を知らない |
| src/data | 数値の表（balance.json）と、その検査（Zod） |
| src/store | ルール本体と画面の橋渡し（Zustand） |
| src/ui | 画面（React と CSS）、音の合成（sfx.ts） |
| src/world | 街の絵（PixiJS）、街ぜんたいの地図の絵 |
| src/save | 保存の窓口 |
| tests | Vitest |
| e2e | Playwright |
